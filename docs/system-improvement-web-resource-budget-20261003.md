## 有界预算

给这批计划交付新增 **32 KiB** 共用资源额度：基础总 gzip 从 281 调整为 **313 KiB**；含现有 screenPanel 额度时总上限从 317 调整为 **349 KiB**，base/shared 为 **309.5 KiB**。相对 r2 的总量余量为 **4,127 B**，后续新增功能不能无限使用本次调整。这是自主实施中的明确预算修订，不表述为用户单独批准过这个数值。

首页 66 KiB、单资源 26 KiB、运行模块 16 KiB、gzip 文件数、静态 DOM 总量/单页限制均保持原值。现有能力裁剪、清单身份、独立懒加载、逐资源检查不变；没有全局属性混淆或删除失败保护。测试继续验证每一项超限会拒绝发布，而不是只验证当前资源通过。

新额度尚须新候选 Web 门禁、浏览器、九环境固件和 LittleFS 构建验证。打包能装入分区不代表设备页面速度、瞬时堆峰值或长期稳定性通过；部署仍需候选身份、现场配置保全与单独授权。当前没有设备访问或新增物理性能结论。
