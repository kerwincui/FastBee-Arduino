# MCP23017 禁用配置样例（开发候选，尚未验收）

[配置片段](mcp23017-disabled-example-20261003.json)仅含6项禁用外设，不含身份、网络、MQTT、用户或自动动作规则。GPIO8/9/10只是演示占位，不能据此认定某块开发板的接线可用。不要直接覆盖设备的peripherals.json；通过配置界面按实际板卡逐项建立并预检，原有配置及逻辑ID保持不变。当前未在任何设备导入或启用此样例。

1. 核实实际板卡、芯片供电/信号电平、地址和RESET外部偏置，选择实际可用的SDA/SCL及独占RESET GPIO。输出低电平只是示例，不表示继电器、驱动器或负载处于安全状态。
2. 先保存禁用I2C总线及专用原生数字输出RESET（初始HIGH、非反相、非PWM），再保存禁用MCP父和3个子通道。A7（7）、B7（15）必须明确为输出；输入用0，不使用7/15，不配置内部上拉。
3. 稳定候选与现场条件获准后，核对总线/RESET接线并先启用这两个依赖。父与子仍保持禁用。父设备启用弹框展示同一快照中的地址、SDA/SCL、RESET、各输出初始物理电平，手动选择A7、B7及需要的输入；不会自动勾选输出。
4. 确认后请求携带本次预览的groupToken。确认期间如有配置修改、重载、退役等版本变化，或设备重启，接口拒绝旧预览并要求重新检查，不自动更新token重试。权限及当前资源校验仍独立执行。
5. 已启用输出复用普通数字高/低、翻转和受支持的低频闪烁路径；输入使用父采样及已有质量状态。未知读数不能当0；不支持PWM、呼吸或硬件中断。规则完整联调尚待最终软件与实物验收。
6. 修改硬件参数前先整组禁用。禁用先保存意图，再按输出配置的初始物理电平尝试停止；总线/回读/资源释放失败显示未确认，不能据配置disabled推断负载已断开。失败不自动复位、重放或恢复旧实例，待退役未完成不能重新启用。

预览只保证管理器正常变更入口的配置一致性；不是授权凭据、物理接线检测或跨文件迁移事务。原始文件写入、重启后真实硬件状态及负载效果仍按各自验收边界处理。本样例、代码及回归准备均UNTESTED，不代替九环境/RGB、实物、真实内存恢复或长稳证据。
