# G02：OLED 地址归属与 U8g2 传输失败

本增量在 r12 于 2026-10-02 13:20:59 冻结后修改主目录，不属于 r12，也未访问设备。

## 问题与修复

OLED 管理器原先只取得共享 I2C 总线，没有声明固定的 0x3C 地址。实际生产准入/回调方法与真实 I2CBusManager 的回归复现 11 项中 5 项失败：允许地址冲突、未持有地址、回调指向其它地址、空数据及短写错误未持续传播。

现在在同一事务锁内申请租约和地址，冲突时释放本客户并停止初始化，探测前及每次 U8g2 传输核对归属。SEND 的短写或无效缓冲标记本次传输失败，后续 SEND/END 不会将它变回成功；END 仍尝试结束本客户事务。释放/重新初始化保持既有延迟回收机制。

原始失败保存在 artifacts/system-plan-oled-i2c-before-20261002-r1.log；修复后 OLED、真实客户退役、U8g2 GPIO 初始化及共享管理器共 **14/14 PASS，9.833s**，见 artifacts/system-plan-oled-i2c-after-20261002-r1.log。未修改门禁阈值或既有失败记录。

## 13:41 高层操作增量（不属于 r14）

U8g2 高层方法返回 void，可能忽略一次回调失败并继续后面的事务。原管理器会将这种初始化、刷新、对比度、显示开关和维护操作视为成功；缺失 END 还可能遗留事务锁。本轮执行真实管理器方法、真实字节回调及共享 I2CBusManager，以模拟的 U8g2 void 调用序列注入“先失败后成功”和缺失 END，先复现 **7 FAIL/11 PASS**。

新增有界的操作级错误标记：每次公开硬件操作开始时清零，任何传输失败持续到本次操作结束；结束时清理残留锁。初始化失败释放本客户，refresh 失败保留待刷内容且不更新时间，失败的对比度设置不覆盖已生效值；成功值保留给后续维护。维护失败不推进成功刷新时间，重试仍保持既有间隔，不能靠快速循环掩盖错误。
