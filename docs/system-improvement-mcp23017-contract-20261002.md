## 官方资料与适用限制

Microchip [DS20001952D 官方 PDF](https://ww1.microchip.com/downloads/aemDocuments/documents/APID/ProductDocuments/DataSheets/MCP23017-Data-Sheet-DS20001952.pdf)已通过直接 HTTPS 下载；40 页，1,019,348 B，SHA256 `63cb5f2bec44434cdeeada1790d0316c9dc06b33febb489ad87bb0e2d540496a`。来源、旧版 C、PNG 和报告在 artifacts/system-plan-mcp23017-source-20261002-r1，原 20261001 的 403 证据不覆盖。

依据 PDF 技能渲染并核对 D 版第 12 页寄存器表及第 18 页方向寄存器注释：**MCP23017 的 GPA7、GPB7 只能作输出，IO7 必须设为 0**。不能依旧版 C 宣称 16 路均可输入，也不能把此限制套用于 SPI 的 MCP23S17。旧版 C 仅保留作历史比较。

## 准备区交付

- MCP23017Contract.h：BANK=0/1、A/B 口的 44 个地址映射；非法 bank/port/register 拒绝。
- 16 位配置严格核验方向、输入、启动锁存、上拉和极性掩码：输入输出不重叠，启动高电平只属于输出，上拉/反相只属于声明输入，拒绝截断超范围整数。为避免静默驱动未声明引脚，项目合同要求显式声明两只 output-only 引脚的输出归属和启动电平；这是本项目准入策略。
- 已知 OLAT 的掩码更新只改变选定的已声明输出，不用 GPIO 实时电平替代锁存值，不允许输入位被写入。
- 所有函数只构造数值，不触碰 I2C/RESET/输出、不分配设备实例。失败结果 valid=false/返回 false，不能忽略结果直接发送清空后的寄存器值。
