# 触控屏通用设备控制

触控屏是可配置的显示和控制入口，不绑定某个电机型号或固定从站地址。
使用已有外设驱动、Modbus 映射和执行规则；没有实现的协议不能仅靠添加一个按钮获得支持。

## 配置路径

1. 在外设或通信协议配置中建立真实设备、通道及映射。Modbus 设备需按其说明书填写从站、功能码、寄存器、数据类型及倍率，不能沿用另一设备的地址示例。
2. 新建或编辑执行规则，设置明确目标与动作，启用规则并勾选“允许设备屏幕控制”。
3. 在“设备屏幕”编辑器中添加控制组件，从可用控制项中选择该规则，再拖拽调整位置和尺寸。
4. 按规则能力选择按钮、数值输入或滑块；仅布尔型控制项使用开关。保存后通过独立读回及现场观察验证效果。

## 已有能力与边界

| 类型 | 配置方式 | 触控组件 |
| --- | --- | --- |
| GPIO 继电器 | 配置有效电平，分别建立固定开启、关闭动作规则 | 两个动作按钮 |
| Modbus 继电器 | 按说明书配置线圈或寄存器写入规则，开启和关闭使用明确的值 | 两个动作按钮 |
| Modbus 数值、PWM、DAC | 使用接收值的受支持数值规则，配置范围、步长及设备约束 | 数值输入或滑块 |
| 传感器 | 绑定已配置的数据源；需要主动采集时另绑采集规则 | 读数、曲线、采集按钮 |
| 步进电机 | 配置驱动器指令、参数读回及精度映射 | 专用电机组件 |
| 远程布尔通道 | 仅在构建启用该能力且通道声明可写时使用 | 开关 |

本地继电器的任意动作规则不等同于布尔开关接口。当前固定开启/关闭按钮路径可用；不要把不支持的接收值规则强行绑定为开关。
控制命令应答、软件估算和真实设备反馈必须分别显示。没有有效读回时不能把“已发送”显示为“已开启”或“正在运动”。

## 权限及变更保护

- 未授权、停用、空动作或不受支持的规则不能从触控屏执行。
- 规则目标和动作绑定有指纹校验。修改通道或动作后需重新确认绑定，不可静默控制新目标。
- 数值控件须通过类型、范围、精度及步长校验；界面范围不能代替驱动器和执行端校验。
- 电机参数未知或操作结果暂时不可用时不能自动重发正转、反转。

## 滑台行程

当前 Web 中的软限位字段以脉冲表示，位置是估算值，不是测量位置或毫米标定。
本次 R13 没有集成 R12 行程保护原型。30 厘米名义行程不能直接换成安全脉冲边界；还缺实测脉冲/毫米、已确认原点和端部余量。
现场没有上下限位开关，不能宣称软件估算能够保证永不撞端。本次不写入猜测值、不执行自动找端或运动验收。
