# Web 软限位行程配置（R20）

## 当前交付状态

已冻结独立候选源码，排除共享工作区其他UART/SPI改动；63项电机、
配置、触控和行程保护回归测试通过。Web包已生成，共57个文件；
压缩后的页面及脚本通过1280/390/320像素浏览器测试。

固件编译仍未取得共享构建锁，等待300秒超时；设备两次预检查
也未完整通过，分别为Web读取超时和健康接口建连超时。失败证据保留。
因此本版本尚未编译固件、烧录或写入设备配置，没有进行实物标定或
电机运动，不能将本地验证描述为设备软限位已启用。

## 配置入口

匹配固件和Web部署后，进入“通信协议 → Modbus RTU → 电机子设备 → 编辑”。
也可在电机控制面板的“行程保护与现场确认”中选择“设置软限位”。
现有开发者模式权限检查继续有效。

每个电机独立保存以下字段：参考点至正向端部、参考点至反向端部、
正反向安全余量，单位均为毫米；另有“控制器计数/mm”换算系数。
弹窗“确定”先修改页面草稿，协议页面“保存”才写入设备；重新打开可核对。
修改行程草稿不会自动覆盖已配置的计数上下限。

## 本滑台提供的数据

按用户最新测量：正向222mm、反向88mm，各保留5mm余量。
相对于该测量参考点的几何范围是-83至+217mm，可用总行程300mm。
这些数据并未在本轮写入设备；换算系数尚未确认，不设置假定默认值。

## 后续自行校准

填写已核对的控制器计数/mm，确认换算及测量参考点后，
点击“换算到计数限位”，会向安全区内取整填入现有计数上下限。
保存限位之后，仍须在电机控制面板确认实测参考位置和静止状态。
控制器参数读回、有限行程映射及整次运动所需空间检查保持不变。
草稿保存和换算均不会启动电机。

设备地址、协议或草稿发生变化后，旧换算确认不能继续使用；
重启或提前停止等导致参考位置不可信时，按现有流程重新确认。
机械端部不作为已经验证的电气限位开关，计数位置也不代表实际位置反馈。

## 通用性与证据

生产逻辑未固定从站8、YF53型号或80计数/mm；继电器控制逻辑未改变。
不支持新字段的旧固件会被界面明确拒绝，避免默默丢失配置。
测试中的3.25计数/mm、从站17及寄存器号仅为离线测试数据，未发往设备。
