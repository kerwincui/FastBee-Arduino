# StamPLC 原适配计划调整说明

更新日期：2026-09-17。

原整板适配计划已由 [FastBee 通用外设能力扩展计划（待审核）](../generic-peripheral-extension-plan.md) 取代，请使用新文档进行范围审核、任务分工和验收。

新的目标是拓展现有固件：通过“外设配置 → 外设执行”使用通用 IO 扩展器和传感器，跨当前支持的 ESP32 系列开发板复用。首批建议为 PCF8574 通用 IO、已有 I²C 传感器配置链补齐和 INA226 电压/电流/功率采集；RTC、SD 记录、基础 SPI TFT 等为独立可选包。

EZData、Home Assistant、StamPLC 专用板级构建环境、固定整板映射和 Modbus 从站不再属于本次计划。原 T00～T23 任务、P1/P2 整板交付层级及其估算已失效，不应继续作为待办清单。

[历史资料核对记录](README.md) 保留供查证。本次仅更新计划文档，未实施固件或操作设备。
