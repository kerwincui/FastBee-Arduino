## 数值域与兼容性

旧PCA前端曾独立限制`pwmHz>=1`、`maxPulseUs<=1000000`，并没有与C++的可表示prescaler/tick域对应。本批改为使用实际基础数值域；频率/脉宽组合仍由原硬件数学合同作最终判断。例如低振荡器频率下的低于1Hz配置可能可表示，这不代表其适用于现场负载。

命令pulse=0仍属于原字面解析允许域，但执行时原脉宽转换会拒绝；angle的字面语法接受有限数值，执行必须再按保存的角度端点检查。表单不将语法通过写成设备执行成功，也不凭描述自动重试或启用输出。

PCA十一字段均需显式提交；描述中的default只用于新建表单，不能作为服务端省略字段许可。IO地址/采样字段在既有API允许省略更新、保留原值或新建缺省，描述required=false；完整Web表单仍要求输入有效值。持久化旧sampleInterval=0仍按20ms处理，编辑时显示同源的明确缺省值；新HTTP请求仍拒绝0。未新增自动迁移、启用或跨设备参数转换。

新Web若未取得`configSchemaVersion=1`或`commandSchemaVersion=1`会明确阻止相关保存；原输入/旧动作载荷保留。部署时固件与Web必须来自同一通过候选，不能将旧固件加新Web当作已验证兼容组合。
