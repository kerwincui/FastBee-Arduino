## 契约与使用

新增固定动作号38 `ACTION_SD_STATUS`，只允许 SDIO（类型37）目标、空 actionValue、useReceivedValue=false。保存、导入、预检和执行共同拒绝无效参数；面板控制、数值历史仍不开放，旧动作号不改动。当前目录另有39温控动作，上限不再停在本专项最初的38；旧固件不支持38，禁用规则不能解除版本不兼容。

新建执行规则可以直接选择“SD 状态快照（只读）”，或从“SD 状态快照 → 定时文本上报”模板预览并填入**禁用草稿**。选择已配置的 SD 外设，平台使用相同外设 ID 的文本属性接收 JSON；模板不会保存、启用或执行。必须先确认当前固件支持动作38。

执行时零等待取得外设管理器锁，核对类型、启用/内存挂起、真实 owner、四引脚和频率，然后获取已有 SD 被动快照。不挂载、不查 FAT、不读写文件；状态未知/忙碌/错误目标/配置变化返回失败和空值，不复用上次结果。

成功例（数值仅为格式示意，不是实测）：

```json
{"schema":1,"mounted":true,"quality":"lifecycle_snapshot","capacityQuality":"last_operation_snapshot","totalBytes":5000000000,"usedBytes":1234567890,"freeBytes":3765432110,"capacityAgeMs":70000,"capacitySampledAtMs":100}
```

容量来自上次成功挂载/写入/删除，年龄不会因规则执行或读取文件而归零。sampledAt与age使用本次启动的64位单调毫秒，不是UTC；2026-10-03增量替换了原32位完整回绕边界，详见下节，仍UNTESTED。未挂载、容量无效或used>total时省略全部容量字段，capacityQuality=unavailable，不能当0。生命周期快照不证明卡仍在线或文件已落盘。错误信息只用固定代码，不泄露路径/别的owner。

结果进入现有执行轨迹、reportAfterExec与启动时只读状态上报；quality与age保留在JSON文本内，remark为sd_passive_snapshot。不会注入数值历史或通用传感器缓存；实时容量条件和文件写动作不包含在本增量。

## 19:34 显式恢复与配置绑定（UNTESTED）

文件列表、读取、写入和删除不再隐式调用挂载：显式卸载或挂载失败后返回SD_NOT_MOUNTED，必须由用户执行挂载/恢复。读取或刷新状态不能创建/fastbee；显式挂载沿用既有沙箱目录初始化，不格式化、不重放先前失败的读写/删除。

开发模式的SD诊断新增“恢复/重新挂载”，确认后仅提交一次recover请求。驱动在SD锁和共享SPI操作锁下核对非空owner，仅释放自身租约再尝试重新挂载；其它客户的租约保留。若共享SPI丢失且仍有其它客户占用，拒绝重建总线，不能抢占。失败报告保留，短写/短读/删除目标无法确认等记录故障；成功重挂载只代表本次挂载接受，不证明介质健康、旧文件完整或写入耐久。

API读写共用SdAccess，在零等待外设管理器锁内核对最初配置代际、类型、启用/内存挂起、owner、四引脚及频率，持有该锁至操作结束。配置变化、锁忙或无法核实归属时拒绝操作。SPI失租约时，被动状态仍保留锁内核实的configurationAvailable配置/历史诊断，但statusAvailable=false，JSON省略mounted及全部容量字段；因此能核验owner并显式恢复，不能把可恢复配置冒充有效挂载/容量。SD/SPI忙仍为未知且不准入。被动查询不增加I/O失败次数、不挂载或查询卡。

API/Web增加recoverySuggested、ioFailures、recoveryAttempts、recoveries和最近lastFailureCode。计数饱和，范围为本配置生命周期：后续成功文件操作或手动卸载/重挂载不会清空故障历史，释放配置/重新配置会重置，重启不持久化。成功挂载清除当前恢复建议，历史仍可见；忙、旧固件和非法/缺失字段不显示正常零故障。恢复请求不携带编辑草稿/路径，失败不自动重试，迟到响应不刷新另一设备。动作38仅增加精简的recoverySuggested/ioFailures/recoveries字段，不自动触发恢复，状态不可用仍返回失败空值。

## 18:38 文件读取/追加边界（UNTESTED）

SD读取不再以无界available循环边读边覆盖调用方内容。现在先检查文件大小和缓冲分配，逐字节校验至初始大小，最终确认大小未变且EOF成立，再移动完整字符串给调用方。空文件是合法完整结果；短读、异常字节、意外剩余或文件增长/缩小失败，调用方旧content不变且不能当成新数据返回。失败关闭句柄，无自动重读；短读/大小变化使历史容量快照失效。后续完整读取可清除操作错误，但不会冒充已重新测量容量。

追加写对现存文件必须先打开且确认不是目录，无法确认拒绝，不将失败size查询当0；边界使用MAX_FILE_BYTES-existingSize，防止整数加法溢出绕过16KiB限制。沿用存储/共享SPI锁和owner校验，未改变现场文件。

Web文本读取要求字符串与返回UTF-8字节数严格一致且≤4096字节，缺内容/长度、类型错误、超限拒绝覆盖草稿；空内容/0字节仍有效。未承诺任意二进制或非法UTF-8文件在文本编辑器无损往返。准备14组真实SD管理器（含SPI替身）和3组真实JS回归，未运行；包含短读后成功及显式卸载/重挂载的恢复路径。真实FAT/拔卡/满盘/断电和底层阻塞时长仍待验，不称SD整项完成。
