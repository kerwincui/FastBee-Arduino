# 当前触控屏使用与配置

> 历史记录：本文描述旧 r6 界面，以下 IP、预览/配置职责及天气入口已不适用于新编辑器。当前操作请参阅[设备触摸屏：预览、编辑与操作](../touch-screen-user-guide.md)，部署状态以本次验证记录为准。

更新时间：2026-09-22。现场触控板 COM8，Web 地址：http://192.168.5.52 。应用为 RGB r6，Web 为匹配 canonical r3；已保存的屏幕配置为 revision 10。当前用户确认画面稳定，完整实体操作与长期验收仍以[实施记录](../screen-panel-implementation-report.md)为准。

## 已配置的页面

| 页面 | 内容与操作 |
| --- | --- |
| 首页 | NTP 时间和日期、可视化天气、SHT30 温度和湿度，下方提供趋势、电机、控制和系统入口 |
| 最近十点 | 温度、湿度各最近 10 个有效采样点；无有效数据不补零 |
| 电机控制 | 保留原有卡片；当前电机断开且规则禁用，不执行运动命令 |
| 场景与开关 | 开关、场景待绑定实际规则；“采集一次”已绑定现有 SHT30 采集规则 |
| 系统操作 | 亮度 25%、70%、100%，立即息屏、短提示音、二次确认重启 |

天气已并入首页，不再占用独立页面。图标、背景、卡片和曲线由固件绘制，无需上传背景图片。天气当前使用已配置的心知来源；城市和 API 来源在“通信协议 → 天气与远程资源”中调整，密钥不写入本示例文档。

## 在物理屏上使用

从首页点“系统”进入系统操作页。亮度按钮调整当前运行亮度；默认启动亮度为 70%，更改重启后的默认值需在 Web“设备屏幕 → 配置”保存。自动息屏当前关闭，避免调试时意外黑屏。

“立即息屏”关闭背光，下一次触摸只唤醒，不同时触发该位置的按钮。“提示音”只短响一次。“重启设备”需要再次确认；本示例已显式允许此操作。页面可左右滑动切换，实际点击、滑动、亮度和蜂鸣器效果仍需在实体屏逐项确认。

## 在 Web 中继续调整

进入“设备屏幕”，使用两个选项卡：

- **预览**：管理页面、添加组件、拖拽调整位置、绑定数据或动作并保存。这里的控制按钮只是预览，不会控制真实设备。
- **配置**：选择显示设备、主题、程序绘制背景、默认首页、启动亮度、自动息屏、系统操作许可和历史来源。

当前现场布局使用 5 页、24 张卡片，已达到卡片总数上限；最多支持 8 页。增加组件前需删除或替换已有卡片，移动或重新排列不占额外名额。公开示例是 4 页、18 卡，不含电机页面和现场天气凭据，不能直接导入覆盖现场五页配置。

远程开关或场景需要先在已有“通信协议”和“外设执行”中建立实际调用规则，然后启用该规则的“允许面板调用”，最后在卡片里选择它。规则修改后重新保存绑定。没有第三方地址和调用协议时保留“待配置”，不显示假开关状态，也不自动调用未知服务。

“采集一次”复用 `collect_sht30`，不会因预览或切页触发。屏幕不负责创建另一套采集或控制逻辑。当前不提供物理屏 Wi-Fi 配网，网络仍从 Web“网络设置”管理。

`collect_sht30` 的默认采样周期为 8 秒，现场也已从 10 秒调整到 8 秒；观测 TTL 保持 10,000 ms，采样频率增加 25%，为调度和 Web 负载留下约 2 秒余量。这是提前产生新样本，不是延长旧值有效期；动作内容、其他规则和电机采集间隔未改，真实超时仍显示 stale。

## 已验证与待验证

当前 r6 的 HTTP 9/9、桌面/手机菜单 24/24、面板 API 15 项、预览/草稿添加/手机布局与 NTP/天气/SHT30/两条十点历史通过。10 秒周期的 120 秒窗口曾有 stale；调整为 8 秒且 TTL 不变后的 180 秒窗口，50 次响应、各 24 个新点、最大间隔 8,868 ms，无 stale 或混代。180 秒串口无复位/panic，但保留一次日志落盘 2,513 ms 超预算告警。

用户本轮确认画面稳定；实体亮度、提示音、点击/滑动及持续负载仍待确认。COM8 单机 24 小时长测已于 2026-09-22 01:33:49 启动，第2轮出现脚本资源长度不匹配和探针超时后重试；第3轮恢复不能抵消失败，尚未通过且不包含其他三台。机器预览与短时结果不能替代长期验收。后续状态见[实施与验证记录](../screen-panel-implementation-report.md)。
