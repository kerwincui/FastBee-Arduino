## 实质开发

`MqttClientLease.h`提供不可复制、可移动的作用域引用；先取得读准入，再读取实例指针。32位lock-free原子计数独占最高位作为写准入，读者最多尝试8次，无等待；争用返回不可用，不假装实例不存在。此机制保护对象寿命，不串行化MQTT内部方法或配置读写，也不拥有ProtocolManager自身。

ProtocolManager的初始化/启动、两种重建入口和停止进入写准入。报告或状态读取仍在进行时，停止/重建保留原实例并排队；loop先完成停止，再处理后来请求的重建。pending改用原子发布，延期不能触发“重建失败→设备重启”兜底。直接重建获得准入后消费此前请求，重建期间新到请求仍留待下轮。终态shutdown封住新借用并等待已借用引用释放，之后才reset；清除停止标记以允许后续initialize。stopAll现在走stopMQTT，停止自动重连，而不只是断开一次连接。

终态等待没有超时，也不能由持有租约的同一任务同步调用；ProtocolManager必须活得比所有租约久。Framework当前先禁用调度任务再shutdown，禁用不等于join，仍需最终验证在途任务退出、管理器所有权和所有调用点。两枚停止/重建标志不是完整带版本的命令事务，不能据此承诺并发配置请求的最后写入语义。

已迁移引用范围：

- Framework注入的连接/报告/事件回调；PeriphExecExecutor脚本执行和报告；PeriphExecScheduler报告、数字输入事件和连接检查。确认不存在实例时保持原禁用捷径；忙锁/待重建时仍可进入离线缓存分支，避免把瞬时忙当“MQTT未启用”而丢弃本次报告。
- ProtocolManager发送/状态、主循环、Modbus分发和OTA发布/命令入口。主循环的租约作用域在测试配置恢复前结束；恢复流程的状态查询持租约、停止通过管理器入口，避免重建永远被自身引用阻挡。
