# G05 只读采集模板向导（2026-10-01 候选）

范围为新增规则的可审查草稿，不是全套场景向导、设备迁移或独立用户验收。

2026-10-03 主仓后继开发新增 [NC03 仪表模板与字序](system-nc03-instrument-templates-20261003.md)：可由厂商资料模板创建禁用 Modbus 读取任务，再供本向导选择。该增量尚未统一测试，不属于下文历史 PASS；下文“未引入仪表模板库”和 compact 字段边界描述的是 2026-10-01 候选。

## 操作流程

1. 先在功能配置和外设配置中保存并启用实际存在的外设；核对接线、型号、供电和校准。向导不会配置这些项目。
2. 在“外设执行 → 新增”展开“从只读采集模板开始”。编辑已有规则时不显示模板。
3. 选择传感器通道、RTC 日历或已核对 Modbus 只读任务，显式选外设/任务，不默认选第一个。传感器通道来自固件 driverDescriptors，并按实际模式过滤，平台字段必须自行匹配物模型；Modbus 的人工核对要求见后续增量。
4. 填写 5～86400 秒整数间隔，且不得低于驱动 minIntervalMs 换算的秒数。默认 60 秒只是可编辑草稿参数，不是实测承载能力。
5. 点击预览，检查目标、通道、平台字段、周期和限制；确认替换当前未保存规则表单后，再填入禁用草稿。输入变化立即使预览与确认失效；应用时重查加载状态、能力和目标。
6. 检查现有规则表单再手动保存。规则保持禁用，默认请求执行后上报，但不开数值历史/屏幕控制。保存仍走原权限、前置检查和服务端合同。应先检查单次读取、数据有效性与平台实际收件，再人工启用。

## 边界

- 传感器模板仅选当前固件注册、模式匹配的通道，沿用外设的接线和校准；动作 19 携带稳定 peripheralId、channelField 和显式平台字段。不替代校准、现场量程或后端能力验证。
- RTC 模板仅动作 36，空命令、禁用 received-value；不产生动作 35/37，不改系统/RTC 时间、充电、电机或输出。日历没有时区，运行且日历有效不等于走时准确。
- 缺失能力目录、失效/错类型目标、未启用外设/功能、未知驱动/通道、错误字段或采样周期均不能生成草稿。仍可能遇到运行时初始化失败/忙锁，由已有执行诊断明确报告。
- 预览通过不代表 MQTT 已连接、云端物模型字段存在、实际上报成功或读取数值可信；需分开确认。禁用草稿不会自动执行，后续启用属于显式操作。
- 无多规则事务、GPIO 迁移、继电器联动或通用仪表模板库；NC01/NC03/NC04、完整 NC02、V14 仍开放。
