输出支持已声明0～15通道、原始phase/width、占空比、微秒脉宽及有界角度映射。脉宽/角度使用共享prescaler计算所得频率，拒绝非有限值、越界、不能区分的角度端点和会变成FULL_ON/OFF的脉宽。占空比仅显式0/100使用FULL_OFF/FULL_ON，中间值量化限制在1～4095，避免接近端点时变成常电平。计算频率和寄存器影子都不是实际波形或舵机角度测量；具体负载的供电/范围仍需实物校准。

运行时核验OE原引脚与所有权，意外门控电平使provider故障并尝试禁用；失去控制权或控制对象换引脚后不向新引脚发命令。Device也绑定首次准入引脚，析构仅在仍持有原引脚时尝试HIGH。停止先请求OE HIGH，再取得总线并退役主地址及0x70，最后释放OE；忙或释放失败保留对象，进入纯释放重试后不重复PWM写入。此前故障或停止失败的终态仍是Error，后续释放成功不抹掉首错/计数；析构不是已确认停止，HIGH也不是负载断电证据。
