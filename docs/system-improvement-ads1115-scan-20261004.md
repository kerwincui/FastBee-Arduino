## 配置与兼容

同一个 I²C 地址只配置一个 ADS1115 外设。默认 scanMask=0 或旧配置没有该字段时，仍使用 mux 选择一个输入组合，输出 voltage（V）和 rawCode（count）。现有单路规则不需要迁移。

需要多路时，在通用传感器表单勾选1～4个输入组合；scanMask 的第0～7位分别对应 MUX0～7，软件按编号从小到大逐个转换。240 表示四个单端输入 AIN0～AIN3 对 GND，144 表示 AIN0/AIN3 对 GND。模式启用后，测量通道为所选 voltage_mux0～voltage_mux7，单位 V；不再提供 voltage/rawCode 别名，避免把旧通道悄悄改成另一输入。切换配置后必须检查规则与迁移预检中的通道引用。

| MUX | 输入组合 |
| --- | --- |
| 0 | AIN0 − AIN1 |
| 1 | AIN0 − AIN3 |
| 2 | AIN1 − AIN3 |
| 3 | AIN2 − AIN3 |
| 4 | AIN0 − GND |
| 5 | AIN1 − GND |
| 6 | AIN2 − GND |
| 7 | AIN3 − GND |

量程、速率和 ADC 校准增益/偏移由同一物理外设共用。每路的工程量比例、偏移和单位在对应采集动作设置。默认增益1/偏移0不代表已经标定；ADC满量程不是端口允许电压，不能据此直接接工业电压/电流。

## 时间、失败与队列

每轮最多4路、只有一个转换会话和一个地址owner，没有后台任务或无界请求队列。每路仍要求旧转换排空、连续模式退出、busy→ready和配置位一致；转换等待位于缓存锁与I²C事务锁之外。相同实例的并发请求收到BUSY，其它实例可在转换等待期间读取或释放。

N路的转换预算为 N×(2×ceil(1000/dataRate)+50) ms，配置采样最小间隔为该预算与100ms的较大值。4路8SPS为1200ms，4路128SPS为264ms。预算用于软件准入与等待取消，不是 SDK/I²C 整笔调用或整个规则的硬实时保证；高转换速率也仍须实测能否观察busy。

一轮只有全部通道成功才公开缓存样本和同轮标识。每路保留自己的真实获取时间；同轮不代表同时采样。失鲜从实际获取时间计算，缓存命中和MQTT到达不刷新时间。任一路饱和、NACK、配置丢失、超时或取消都使整轮无效，不发布部分数字或有效零值。驱动返回失败终态时，诊断可查看本轮已获取通道、故障位置及未尝试通道，但不能把诊断值当有效控制输入。新扫描开始即清除上一轮诊断；若缓存总预算超时或无法重获锁，尚未收到驱动终态诊断，则通道列表为空，只保留整体失败/待回收状态，不把旧值或无法确认的局部值当成本轮诊断。

释放、重建、配置代际变化会取消在途扫描；旧token不再访问驱动。无法及时重获缓存锁的扫描到期失败，之后没有后台I/O；下一次显式读取或释放回收过期状态。批量动作仍要求同一外设、同一配置及同一成功扫描标识，混合扫描和旧实例不能合并发布。
