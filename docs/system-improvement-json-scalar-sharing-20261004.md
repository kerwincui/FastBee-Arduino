# 固定JSON字段的数值写入共享

当前候选在r55的既有嵌套/数组和相关消费者差分通过；新增根布局夹具编译问题保全并修正后，r56原代理边界与逐分配故障等11项全部通过，且与图/雷达合计47项独立保全。此变化用于解决原分区的镜像容量阻断，实际节省尚待C6镜像实测；未调整功能开关、分区、字体、异常支持或发布预算。

原固定字段helper已经共享成员查找，但每个调用处仍实例化并展开数值转换。现将bool、32/64位有符号/无符号整数、float、double和nullptr的实际ArduinoJson写入分别集中到禁止内联的函数。小整数按相同符号扩宽到32位；32位以上保留64位，double不降为float。ArduinoJson仍自行决定32/64位数值存储和扩展槽分配，原返回值、覆盖清理、未绑定字段及内存不足行为不变。

字符数组仍走原容量元数据/借用策略，普通字符串、JsonString、枚举和自定义转换器保持原转发。数值引用读取在字段查找后发生；调用者原RHS表达式仍在查找前求值。没有新增JSON字段、常驻缓存、重试或内存分配器。

`test_fixed_json_document`新增六种document/object与一至三级字段布局的实际ArduinoJson代理差分：每种整数类型的极值及32/64位边界、正负零、浮点次正规数、无穷/NaN和空值；空/对象/数组/标量根以及逐次/持续分配失败。逐步比较JSON字节、类型、返回值、溢出状态和分配/释放轨迹。既有嵌套/数组/所有权/RHS/异常/完整消费者差分一并复验，随后使用真实C6应用BIN判断是否有收益。新增任意枚举探针在当前AJ Host配置的原始代理就无法编译，r55原FAIL保留，移除此不被原库支持的额外探针；生产枚举转发路径未改。Host通过不代表设备内存峰值、性能或容量通过。
