# PCA9685 默认禁用配置样例

2026-10-04补充：整设备来源仲裁已接入，相关管理器/HTTP及参数表单Host子集在集成定向r4通过，原整组UART夹具失败单独保留并修复；仍须完整目标构建、浏览器及实物验收。以下早期UNTESTED描述保留其历史开发时点，不代表当前测试数量为零。

同一PCA设备的全部通道共用控制权，规则和网页不能交叉抢写。普通enable/duty/pulse/angle要求可信来源，网页会话默认占用30秒，规则沿用本次调用；覆盖须服务端验证完整目标、配置版本和占用代际。无上下文的旧入口拒绝，普通操作不隐式准备或初始化。

disable/stop在认证和开发者权限检查后仍可作为紧急操作，先撤销旧操作的后续写；在途调用未终态前不能重新prepare。普通来源退休保留当前PWM/OE，不发送猜测的零占空比。显式stop的成功说明资源已退休；历史I/O错误及physicalOutputVerified=false保留，不能称负载已断电。

开发状态：UNTESTED，未构建、未导入设备、未观察实际输出。配套 [JSON](pca9685-disabled-example-20261003.json) 仅供配置参考；GPIO8/9/10 是占位接线，必须按具体板型更换，不能照搬到 ESP32/C3/C6/S3 的所有板卡。不要覆盖已有配置或启用真实负载。

生产类型为 `PCA9685_PWM`（57），最多一片，引用一个 100/400 kHz 的 I2C 主总线和一个专用原生 GPIO 输出。OE 输出必须初始 HIGH、不反相、非 passive，外接上拉；不能与 MCP RESET 或其它负载共用。主地址 0x40～0x77，排除 0x70；运行期间同时保留 0x70 all-call 地址，禁止其它客户占用。没有广播复位、外部时钟或数字输入功能。

所有通道共用 `pwmHz`，`clockHz` 是内部振荡器估计值。`channelMask` 的位 0～15 声明可写通道；样例只声明通道 0。角度与脉宽端点需匹配负载，并能转换成当前频率下不同的有效 tick。页面显示计算频率，不宣称实际脉宽或角度。

在具备现场授权、配置保全和接线确认后，按顺序操作：

1. 保存并逐项启用总线、OE、PCA 配置。PCA 配置启用只表示软件配置可用，不初始化芯片、不放开 OE。
2. 在 PCA 诊断面板点击“准备”。这一步占有 OE 并请求高电平，返回绑定当前配置的 60 秒一次性确认；不是只读操作。
3. 保持主控供电，在 OE 保持禁用时对 PCA 芯片断电再上电，核对本次接线后勾选确认并点击“初始化”。软件无法证明实际上电，不能只刷新页面代替这一步。
4. 等待后刷新状态，确认“就绪，输出禁用”；设置声明通道，然后单独选择“启用输出”。失败或未知响应不自动重试，也不重放旧占空比。
5. “禁用输出”保留会话；“停止并释放”会退役主地址/0x70 和 OE 租约，释放驱动对象。关机、功能关闭、内存降级或配置版本变化也会停止；重新恢复仍须新鲜上电确认。关闭窗口不会自动停止已启用的输出。

规则使用动作 10（调用外设），目标固定为 PCA 的 ID；示例参数 `{"action":"duty","channel":0,"value":10}`，也可用 `pulse`（μs）、`angle`（°）或不带 channel/value 的 `enable`、`disable`、`stop`。仅接受固定 JSON，拒绝 `$value`、接收值替换、prepare/start 和任何确认令牌。规则只能操作人工初始化后的会话；本地接受不表示负载动作或平台收件已验证，不作为数值采样历史。

规则编辑器为 PCA 提供动作、通道和数值表单，自动保存上述固定 JSON，不要求手写参数。

管理器在就绪及已启用阶段持续复核本地 OE 归属和预期 pad 电平；异常进入故障并尝试禁用，后续不自动启用。这不等于持续读回芯片寄存器或测量真实输出。服务阶段拒绝非 PCA 类型，切换逻辑设备 ID 不沿用上一设备的错误显示。
