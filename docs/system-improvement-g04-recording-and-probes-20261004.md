# G04：SD连续记录、UART错误与DS18B20身份绑定

2026-10-04开发增量。原计划§8.1的三项软件漏项已接入，待同源门禁；本文不声明部署、实物或长期验收通过。

- SD动作40使用现有type37 SDSPI owner；动作38只读状态、39温控保留。唯一action19数值历史来源、默认禁用独立规则、8条队列、2KiB批次和会话内有限轮转。保留先前会话文件；FAT大小写、点路径与短名不能绕过记录文件写/删保护。忙锁未尝试写入可下次提交；可能已写的失败锁存、丢弃队列、不重放，显式SD恢复才新建会话。SDK写入/flush不等于断电持久性。
- 通用UART通过已安装Core3异步错误回调观察FIFO/缓冲满/帧/奇偶/BREAK，首次错误原子撤销接收代际，使读取、分帧及排队来源失效。显式停用/启用清旧驱动和缓冲，迟到旧回调不可撤销新代际。SDK事件可能延迟/丢失，公开注册接口无法确认事件任务创建成功；`hardwareErrorDeliveryConfirmed=false`，零计数不是正常线路证明。
- DS18B20的`deviceAddress`为可选16位十六进制ROM，家族0x28、CRC8须正确；为空保持索引0–15兼容。指定地址消失不回退索引。OneWire转换广播后立即释放全局传感器锁，公有读取入口在任务内yield等待剩余转换时间（最多750ms），再重新加锁核对不复用实例代际；等待期间不保留原指针，其他传感器和release可以运行。
- 温度样本时间取64位转换请求时间，最大新鲜年龄1750ms，旧值不能刷新时间。慢轮询会重新请求转换并受控等待；多ROM可共享一轮已完成转换。release/reinit、时钟倒退或失效不能交付旧实例结果。采用受控等待避免把正常转换交给规则30秒失败退避，原失败/联动/上报语义保持。

新增测试覆盖真实SD存储/记录核心及Web/导入、UART实际setup/read/scheduler/来源守卫、DS18公有读取/内部转换步骤/ROM解析/表单/owner；集中结果以实施记录和新报告为准。审查已修复SD保留名大小写别名；DS18转换等待改为锁外有界yield，避免改变调度器退避和失败联动来迁就采样实现。
