## 已落地的纯函数

- ADS1115Contract.h：完整 8 路 MUX 编码、6 种 PGA 缩放及 8 个采样率；只构造单次转换、禁用比较器的配置；解码全部 16 位二补码，输出 code-rail 标志。非法参数先清空输出并拒绝，非法缩放返回 valid=false/NaN，不伪造有效零值。名义采样周期不是完成/超时判断；未来驱动仍需拥有地址、确认 idle、轮询 OS 和处理取消/断线。
- PCA9685Contract.h：按官方 round 公式选择 3～255 分频并返回给定时钟下的计算频率；16 通道、12 位相位/宽度，0%/100% 使用独立 full-off/full-on 位，中间占空比禁止相等 ON/OFF，支持跨周期。仅输出寄存器字节，不触总线；不在此函数实现 SLEEP/唤醒或继承未知硬件状态。
- 两个头文件没有被生产驱动注册/实例化；正常固件功能不因此增加。将来集成不得绕过 I2C 生命周期、字段质量、配置持久化、动作预检和功能准入。
