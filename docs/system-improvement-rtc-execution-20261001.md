# RTC 规则启停：执行契约与验收边界

日期：2026-10-01。属于 [整体计划](system-assessment-and-improvement-plan-20261001.md) G04 增量；具体候选、测试与构建终态以 [实施记录](system-improvement-execution-20261001.md) 为准，不代表 G04/G05 整包完成。

## 已实现范围

- 稳定动作 ID 35：ACTION_RTC_CONTROL，目标是已配置的 DS1302 RTC（外设类型 50）。不重用历史动作 ID。
- actionValue 只能是 start 或 stop；useReceivedValue 必须 false，空值/未知值/JSON/模板/大小写别名均拒绝，不猜测默认操作。
- 启停只修改 RTC 计时状态；不写日期、系统时间、充电模式或电池配置，不自动调用 NTP。暂停计时不等于释放 GPIO 或停用驱动。
- 不作为数值数据源、历史记录、MQTT 数值属性或面板控制动作；已有规则轨迹仍记录本次执行成功/失败。

## 表单操作

1. 核对板卡接线、DS1302 功能及外设配置；未初始化或日期无效时，先通过现有外设操作页设置有效日期。
2. 在外设执行规则选择“RTC 计时启停”，选择 DS1302 外设，再明确选择“启动计时（不校时）”或“暂停计时”。初始不自动选择命令。
3. 根据实际业务配置触发条件；建议首次保存规则保持禁用，核对后再决定是否启用。本文不会自动保存、运行或修改现场规则。
4. 执行后分别查看规则轨迹、RTC 面板状态和时间推进。启动成功不证明时钟走时精度或电池断电保持；暂停后时刻不再推进是预期影响。

选项只列类型 50，可保留未启用目标用于预配置。失效/不匹配目标保留为不可用项，不重定向到其他外设。切换触发类型不丢失 RTC 命令；含 modbus: 的错误目标不得被转换为 Modbus 操作。

## 准入与并发

RtcAccess 在外设管理器递归锁内重新读取配置与运行状态，核对功能准入、初始化状态及 CE/IO/SCLK。Web 状态/读取/写入与规则使用同一访问封装，串行于现有初始化/重配/停用路径。锁等待上限 50ms，不代表 HTTP、调度或硬件总耗时的硬保证。

| 失败标记 | 本次处理 |
| --- | --- |
| DS1302_ACTION_INVALID / DS1302_NOT_COMPILED | 不操作 GPIO；修正规则或选择包含该能力的固件 |
| DS1302_BUSY | 不操作 GPIO；本次失败，等原操作完成再重试 |
| DS1302_TARGET_INVALID / DS1302_OWNER_MISMATCH | 不操作 GPIO；核对目标类型与当前实例引脚，不自行重绑 |
| DS1302_NOT_READY / DS1302_NOT_INITIALIZED | 不操作 GPIO；保留用户启用意图，先恢复实际实例/功能准入 |
| DS1302_INVALID_DATA | 只完成读取，不写计时寄存器；核对接线/有效日期 |
| DS1302_RUNNING_VERIFY_FAILED | 写后读回不一致，本次失败，不能作为时钟运行证明 |

启停前读取完整有效日历，避免断线返回字节仅凭 CH 位被当作成功；当前计时状态已匹配时不重复写寄存器。这里的校验不是对 DS1302 电气连接或应答机制的替代。底层驱动仍为既有单例，不是新增多 RTC 实例支持。

## 兼容与回退

旧动作编号和已有规则语义不变。新固件配置上限允许 35、拒绝 36 及以上；语义校验另外约束 RTC 命令、目标和触发值替换。未包含本增量的旧固件不识别动作 35，不能直接导入带动作 35 的新配置。回退应使用添加该动作前的保全配置；仅禁用含新编号的规则仍不足以满足旧固件结构校验。

## 证据与剩余工作
