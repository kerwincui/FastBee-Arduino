# G04/type60：规则完成与动作21固定事件联动防环

## 当前证据

原“指定规则完成联动”已由父任务执行 r45 四个资源配置及四个故障变异，并在 r47 与配置持久化回归一同通过。这些是原完成联动的本地证据。本次动作21扩展状态为 IMPLEMENTED_ARTIFACT_NOT_RUN；新回归、整包构建与设备验收须单独记入后续报告，不能继承原 PASS。

## 问题与行为

完成联动的500ms冷却不能阻止执行耗时较长的 A→B→A。进一步确认：A 监听 wifi_connected 并用动作21发 ntp_synced，B 反向监听和发送；合法的1200ms动作延时使每次重入超过普通事件的1秒冷却，成功作业释放运行标记后仍能继续排队。有限观察重复12次、队列仍有第13次待执行的夹具用于复现，不宣称跑了无穷长实物试验。

RuleCompletionGraph 使用实际 ResourceProfile 容量，当前 C3/classic/C6/S3 为12/16/24/32规则。启用图含两类精确 ID 边：规则完成 ID 指向监听者；动作21可静态确定的发出 ID 指向监听者。动作21的显式目标即使暂未注册 DEVICE_EVENT，也按潜在边检查，避免日后新增外设使已接受配置形成循环。负载过滤条件不作为边永不发生的证明；星号只作为字面 ID，没有通配语义。动作22/23不直接成为事件边。

旧动作21缺少显式目标时，固定 actionValue 或空值回退到规则 ID 仍可分析；useReceivedValue 且无显式目标的旧动态事件 ID 不再允许自动运行：启用配置在图/文件/加载准入返回 CONFIG_RULE_EVENT_DYNAMIC_TARGET，保留原文件和旧内存。禁用旧草稿可载入供修复；启用前须填写固定事件 ID。Executor 对该条件也直接返回失败与同名原因，连手动执行禁用草稿都不分发本地事件或发布 MQTT。新保存本来就要求显式事件目标，未新增缩短事件 ID 的限制。显式目标仍允许 useReceivedValue 作为动态负载，不将负载误当事件 ID。

- 新增、修改、启用、完整 JSON 校验、普通保存、流式校验/审阅/导入和旧加载使用同一启用图。自环或组合环返回 CONFIG_RULE_EVENT_CYCLE，图/动作/触发器容量越界返回 CONFIG_RULE_EVENT_GRAPH_LIMIT。
- 禁用草稿可保存；启用时再次检查。旧加载失败保留原字节、旧内存与加载失败状态。恢复须导入修正全部环的完整配置；剩余环仍会令单条修改回滚。
- 完成通知和普通事件分发都在规则锁内防御异常图；不在锁内查询 PeripheralManager。原 UART 来源、修订号、冷却和准入继续生效。
- 流式首遍复制精确发出 ID，逐规则去重，以便后续规则的触发器可匹配前后任意来源。临时复制 OOM 返回 CONFIG_MEMORY_PRESSURE；不以截断或哈希代替 ID。所有复制含结尾零字符的累计字节最多96KiB，超限拒绝；完整 JSON 已有字段直接借用建图，不创建流式索引，不重复复制字符串。

## 回归与资源边界

test_rule_completion_graph.py 提取真实 Manager/ConfigStore/Queries 方法，新增真实普通事件匹配器及真实 Executor 动作21分支；旧普通事件匹配器单独冻结为负例。SDK时钟、队列接受点、存储和外部 UART 是夹具边界，不访问设备、MQTT网络或输出。新增覆盖延时 A/B 重入、CRUD与草稿、混合完成/动作21边、未知未来事件、字面星号、长 ID、文件审阅/导入/加载、OOM与累计内存上界；第五个变异移除普通事件运行时图保护，另两个变异分别移除逐分配准入和分配后余量检查，须由真实行为断言拒绝。完整文档建图有零分配断言，流式累计上限、逐次余量变化、分配器返回时余量下降和 OOM 均单独覆盖。原四个变异和用例仍保留。旧动态目标另覆盖缺省启用/显式启用拒绝、禁用草稿保留、启用事务回滚、补目标恢复、运行时内部绕过拦截，以及独立真实 Executor发布夹具的手动执行拒绝。

内存内规则图不新增堆分配或常驻状态。32位 ABI 估算原32节点图168B、两组32指针256B、32入度128B；这些不是实际编译器栈帧。配置索引新增 profile×4 个临时指针（12/16/24/32规则分别192/256/384/512B）和一个累计计数；仅流式入口的精确字符串短期占堆，累计不超过96KiB；它与当前单规则解析文档及旧 live 规则叠加。每一次复制按实际 length+1 在分配前检查 DRAM余量与连续块，分配后再次检查余量下限以包含分配器开销，失败释放本次块并返回 CONFIG_MEMORY_PRESSURE。先前规则的索引仍占用本次校验内存，直到作用域退出统一释放。原配置文件96KiB限额不等于可用堆承诺，C6无PSRAM可能远早于上界拒绝；不会据此写新配置、发布新规则图或擦除原文件。实际占用取决于字段内容且通常远小于上界，不能以理论有界替代 C6/C3 编译容量、设备堆/栈高水位实测。

动作21 MQTT重复/越权发布另包修复；当前防环包不宣称覆盖MQTT往返、外部控制反馈、断线恢复、实物输出、完整内存/资源、RGB或24h/7d/V14。没有扩大现场授权。
