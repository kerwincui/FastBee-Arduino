# 设备触摸屏：统一编辑与实体操作

适用版本：touch-editor-r2。本文对应统一编辑工作区，适用于具备相应显示、触摸和外设能力的设备。是否已经部署以及实机测试结果，以本次部署记录为准；本文不是实机验收报告。实现范围与待验收项见[设备触摸屏改进计划](设备触摸屏改进计划.md)。

## 一个工作区完成编辑

| 入口 | 用途 |
| --- | --- |
| **左侧** | 页面、布局模板和组件库。支持单击添加或拖入画布。 |
| **中间画布** | 实时显示当前草稿和设备数据；尺寸、位置、标题和来源改变立即更新，不需要另切预览页。控制展示不执行真实设备动作。 |
| **页面属性 / 组件属性 / 全局属性** | 明确切换右侧属性；查看页面或全局属性不会丢失已选择的组件。手机使用可关闭的属性抽屉。 |
| **更多** | 天气配置、数据记录、导入和导出布局。 |
| **保存并应用** | 唯一的统一保存入口；画布实时变化不等于已经写入设备。 |

预览不是设备逐像素截图，也不能证明实体触摸命中、亮度方向或蜂鸣器已经正常。上方“运行状态”区分配置保存和设备应用状态；若提示“重启后应用”，需完成重启再检查实体屏。

## 从一个组件开始

1. 进入“设备屏幕”，选择已有页面，或选择模板后新增页面。
2. 从组件库拖入一个组件；也可单击组件添加，便于触摸操作。可用组件包括时钟、数值、趋势、心知天气、电机、受限控制、执行一次及屏幕系统操作等，实际选项受设备能力限制。
3. 在画布选中组件，调整位置和大小，在属性区设置标题、来源或动作绑定。画布显示的是草稿。
4. 单击“保存并应用”，确认“已保存”和设备应用版本；重新载入可核对实际保存结果。

“生成起始界面”适合需要重新组织页面时使用；已有布局应先从“更多 → 导出”备份。导出布局不含天气 Key。支持的页面数、卡片数以界面提示为准，不能通过重复添加组件绕过设备容量限制。

编辑器的撤销/恢复用于布局调整。浏览器重新打开时可能提示恢复布局草稿；只恢复同一设备 MAC、同一配置版本的草稿，同一 IP 换机不会恢复原设备草稿。无法确认设备身份时暂停草稿恢复和本地写入，并保留已有草稿。恢复草稿不等于写入设备。未保存的天气 Key 不写入本地草稿，关闭或刷新页面后可能需要重新输入。

## 尺寸、拖拽与数据来源

组件属性提供小、宽、大预设，以及横向位置、纵向位置、宽度、高度四个逻辑像素输入。修改预设或像素尺寸会转为自由布局，立即更新画布，不重新排列其他组件。无效中间输入不会写入草稿；越界、尺寸不足和重叠会提示原因。电机等交互组件保留必要的最小触摸尺寸。

自由布局支持拖动组件和右下角缩放。新增组件寻找空闲位置，不挪动已有组件；空间不足时需要缩小组件或新增页面。拖动重叠、触摸取消会恢复原位置；后台状态刷新不会中断正在进行的拖动。模板的“重新排版”则明确重排整页。

| 组件 | 可配置绑定 |
| --- | --- |
| 数值、状态 | 从设备公布的数据来源选择，不固定某个传感器。 |
| 仪表、柱状、折线 | 选择数值来源；柱状最多比较四个不重复、同单位的来源。仪表和柱状支持量程；折线根据真实历史自动缩放。 |
| 开关、执行一次、数值控制 | 选择已获面板控制许可的控制来源；显示形式匹配来源类型。 |
| 电机 | 选择已配置的电机，并配置初始参数和调节步长；不通过编辑器发送电机动作。 |
| 页面入口 | 从当前页面列表选择跳转目标。 |
| 天气 | 共享可编辑的城市、Key、更新周期，不固定城市；目前只支持心知天气。 |
| 时钟、系统操作 | 使用本机时钟和对应系统能力，不伪装成任意传感器绑定；相关默认行为在全局属性配置。 |

暂时不可用或已删除的原绑定会明确显示并保留，不因修改标题或尺寸静默清空。真正失效的绑定需重新选择，不能通过保存绕过校验。

## 心知天气只配置一次

1. 添加并选中“心知天气”组件，在其属性区启用天气。
2. 填入自己的 API Key 和城市，例如云南曲靖填写 `qujing`；城市格式应符合心知天气要求。自动更新可选 15、30 或 60 分钟，默认 30 分钟。`ip` 按请求公网出口自动定位，可能与设备实际所在城市不符；固定场所建议填写明确城市。
3. 单击底部“保存并应用”，保存成功后再使用组件属性中的“更新天气”。有未保存天气修改时，先保存再刷新。

所有天气组件共用同一份服务配置与缓存，不必逐个填写 Key。该组件固定使用心知天气实况、简体中文和摄氏度，没有其他供应商、预报、鉴权或字段映射表单。缺失湿度不会补成 0。

Key 已设置时留空表示保留；勾选“清除 Key 并停用天气”并保存才会清除。删除一个天气组件只删除显示引用，不会自动清除共享 Key。

“更新天气”的手动间隔至少为五分钟。自动重试时间和手动刷新冷却分别显示；离线、未校时、升级或内存不足时，界面说明等待的条件，不保证固定三十秒成功。恢复条件后自动重新准入；请求失败保留最近一次有效数据，并标示过期状态。蜂窝网络当前不支持此天气 HTTPS 路径。

旧配置有多个来源时需选择保留来源。若其他来源仍被外设执行规则引用，保存会拒绝，并要求先调整相关绑定，包括停用规则中的绑定。天气保存期间会临时阻止并发规则配置修改，避免引用检查之后新增绑定；若另一窗口提示迁移忙碌，等待本次保存结束再重试。迁移不会把其他来源的规则自动改到不同城市。

## 页面外观与全局设置

“全局属性”集中管理显示设备、主题、背景、默认亮度、自动息屏、触摸提示音、控制确认间隔、重启许可及底栏页面。

选中画布空白处或进入页面属性，可设置本页主题和背景。默认选择“继承全局”；独立设置只影响本页。全局主题改变后某一页没有变化，先检查该页是否使用独立主题，将其恢复为“继承全局”后再保存。

全局修改首先影响编辑草稿，保存后才交给设备应用。核对上方运行状态，不能仅凭 Web 草稿变化认定实体屏已更新。显示设备变更等需要重新初始化的设置可能提示重启。

## 趋势与最近十条记录

选中趋势组件，设置要展示的数值来源；其属性区同时提供共享的“最近记录”设置。启用数值历史并选择记录来源，随后统一保存。每个来源最多保留十条有效记录。

“全部已开启记录的数值来源”表示不额外限制来源，并不会自动开启每条外设执行规则的记录功能。需要记录某条执行规则的数据时，仍应在“外设执行”中开启该规则的记录选项。历史由共享服务采集，删除趋势组件不会自动删除其他功能使用的历史。

列表中暂时不可用的已选来源会保留，不应因设备临时离线而静默删除。没有有效数据时显示缺失状态，不用零值伪造曲线。实体趋势图用于阅读数据，点击图表不执行动作，允许从图表区域发起页面滑动。

折线默认包含点和连线，没有单独的散点模式开关。此前多个数据源交替采样时只显示点，是错误地要求全局采样序号逐一连续导致的缺陷。现在依据实际采样时间连线；超过典型采样间隔三倍的断档，以及无法比较的重启前后时钟仍断开。单条记录只显示一个点属于正常情况。Web 中的历史数据会持续刷新，并合并同一来源的在途请求。

## 提示音开关、时长与音量

- 是否在触摸操作时反馈：在“设备屏幕 → 全局属性 → 触摸提示音”设置并保存。
- 提示音时长：在“外设配置 → 对应显示外设 → 触摸提示音时长”设置。常用选项为 20、30、60、100、150 ms，默认 30 ms；这是显示外设自身的保存入口。
- 当前 Waveshare CH32 板载蜂鸣器为固定音量，时长不是音量。当前实现没有该板的可调音量滑块；不支持蜂鸣器的显示设备会显示相应能力提示。

触摸反馈与“外设执行”中的独立蜂鸣动作不是同一项。持续鸣叫属于需要排查的异常；本轮有关闭失败重试和启动关闭措施，但实体启动、息屏和异常总线恢复仍需验收，不能据此承诺任何硬件故障下都能立即静音。

## 实体屏操作

| 操作 | 当前设计行为 |
| --- | --- |
| 页面跳转 | 五页以内使用底栏直接跳转；首页保持可达。超过五页时末项为“更多”，打开页面列表。具体页名来自保存的布局，不强制每台设备都有电机页。 |
| 左右滑动 | 页面间切换；只读卡片与控制卡片外框不执行动作，拖动滑块时由滑块接收拖动。 |
| 电机控制 | 使用组件内明确的正转、反转、停止及速度、脉冲控件。首次控制和超过配置闲置时间后重新确认；停止免确认。需要有效外设绑定、规则许可和真实反馈。 |
| 调整亮度 | 支持连续亮度的设备用滑块；逻辑 100% 为最亮，0% 保持最低可见亮度。显示设备极性必须与硬件匹配。 |
| 立即息屏 | 使用明确的息屏按钮关闭背光。触摸任意位置唤醒，首次触摸只唤醒，不同时执行原位置的动作。 |
| 自动息屏 | 全局设置可选择永不或指定闲置时间；默认亮度等持久设置应在 Web 保存。 |

动作不可用时先检查来源、设备在线状态、外设执行规则及“允许面板控制”许可，不把“未知/不可用”直接解释为接线错误。Web 预览正常不能替代电机只执行一次、实体停止时延及触摸手感验收。

## 保存冲突与部分成功

“保存并应用”依次协调天气、最近记录和屏幕布局。只有改动的部分需要写入，但这不是跨文件原子事务：单个配置文件使用其受控原子写入机制，不代表三项同时成功或同时回滚。

若提示“天气已保存；屏幕布局未保存”等，应按提示处理未完成项；已成功的配置可能已经生效，草稿会尽量保留，不要把整批修改理解为全部取消。继续保存前核对组件绑定和运行状态。

若提示配置被其他窗口修改，当前保存会因版本冲突拒绝。先保留并核对草稿，再重新读取设备配置、合并自己的修改后保存；避免两个窗口同时编辑同一资源。未保存的密钥只能在当前页面内保留，不能依赖浏览器草稿恢复。

## Waveshare 本机背光极性修正

2026-09-25 用户实物确认：本机 `backlightActiveHigh=true` 时 100% 黑屏、0% 最亮，配置方向反了。该显示外设 `panel_display` 应改为 `backlightActiveHigh=false`，公开[显示外设样例](device-test-configs/com8-com9-esp32s3-touch/config/peripherals.json)已同步；其他设备仍按各自背光电路配置。

在“外设配置 → 显示外设”关闭“背光高电平有效”，保存后重启设备使显示运行时重新初始化。该板正确映射为 100% 最亮、0% 保留约 10% 可见亮度，立即息屏才关闭背光。部署后的实际亮度递增、最低亮度、息屏与触摸唤醒仍待现场确认；本次用户反馈确认的是旧配置方向错误，不能替代新配置效果验收。RGB 缓冲、时序及卷边保护仍以[板级说明](waveshare-esp32s3-touch-lcd4/README.md)和构建合同为准。

本说明不将旧 r6/r19 的 Web、天气或短时运行记录计为当前版本验收。当前版本仍应分别记录本地测试、真实设备检查和长期稳定性结果。
