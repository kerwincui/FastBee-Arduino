# FastBee-ESP32 多设备并行部署快速指南

## 🚀 快速开始 (30 秒完成部署)

### 前置条件
1. ✓ 4 台 ESP32 开发板通过 USB 连接到电脑
2. ✓ 识别到的 COM 端口: COM4(C3), COM11(C6), COM15(S3), COM16(经典)
3. ✓ Python 和 PlatformIO 已安装
4. ✓ WiFi 网络可达

### 一键部署命令

```powershell
cd d:\project\gitee\FastBee-Arduino

# 方式 A: 同时部署所有 4 台设备 (推荐)
.\scripts\deploy-multi-device.ps1 -AllDevices

# 方式 B: 逐个设备部署
.\scripts\deploy-multi-device.ps1 -DeployC3 -DeployC6 -DeployS3 -DeployClassic

# 方式 C: 只部署特定设备
.\scripts\deploy-multi-device.ps1 -DeployS3  # 仅部署 ESP32-S3
```

### 部署流程说明

脚本会自动执行以下步骤:

```
[阶段 1] 构建固件 (并行)
  ├─ 构建 esp32c3-F4R0 (C3)
  ├─ 构建 esp32c6-F4R0 (C6)  
  ├─ 构建 esp32s3-F8R4 (S3)
  └─ 构建 esp32-F4R0 (经典)

[阶段 2] 烧录固件 (串行，避免 USB 带宽拥塞)
  ├─ COM4: 检测→擦除→烧录→验证
  ├─ COM11: 检测→擦除→烧录→验证
  ├─ COM15: 检测→擦除→烧录→验证
  └─ COM16: 检测→擦除→烧录→验证

[阶段 3] 配置导入 (手动 Web API)
  ├─ 获取每个设备的 IP 地址
  ├─ 生成 curl 命令导入配置文件
  └─ 可选：打开串口监视器查看日志
```

## 📋 各设备对应配置

| 设备型号 | COM 端口 | 固件环境 | 配置文件 | 主要功能 |
|---------|---------|---------|---------|---------|
| ESP32-C3 | COM4 | esp32c3-F4R0 | esp32c3-deployment-config.json | DHT11 + OLED + LED |
| ESP32-C6 | COM11 | esp32c6-F4R0 | ecm50a-full-config.json | OLED + 继电器+AI/DI |
| ESP32-S3 | COM15 | esp32s3-F8R4 | ecm50a-modbus-ethernet.json | Modbus + 以太网+4G |
| ESP32 经典 | COM16 | esp32-F4R0 | puzhong-esp32-config.json | DHT11 + OLED + LED |

## 🔍 常见问题排查

### Q1: 无法检测到某个 COM 端口
```powershell
# 检查设备管理器
Get-PnpDevice | Where-Object {$_.Status -eq "OK"} | Format-Table

# 重新插拔 USB 线或使用不同接口
```

### Q2: 固件构建失败
```powershell
# 清理缓存并重新编译
pio clean -e esp32s3-F8R4
pio run -e esp32s3-F8R4
```

### Q3: 烧录过程中断
```powershell
# 可能需要按住 BOOT 键再重启设备
pio device monitor --port COMx --exit-on-reset=false
```

### Q4: Web 界面无法访问
```bash
# 查询设备 IP 地址
ipconfig | findstr "WiFi"  # Windows
ifconfig                     # Linux/Mac

# 使用默认 AP 热点 IP
http://192.168.4.1
```

### Q5: MQTT 连接失败
```bash
# 检查 WiFi 配置
curl http://<IP>/api/network/status -H "Authorization: Bearer <TOKEN>"

# 验证服务器可达性
ping iot.fastbee.cn
telnet iot.fastbee.cn 1883
```

### MQTT 可靠性测试
```bash
#!/bin/bash
# mqtt_test.sh
TOTAL=100
SUCCESS=0
for i in $(seq 1 $TOTAL); do
    mosquitto_pub -h iot.fastbee.cn -p 1883 \
        -t "fb/iot/FBE_XXX_001/data" \
        -m "{\"seq\":$i}" > /dev/null 2>&1 && SUCCESS=$((SUCCESS+1))
done
echo "成功率：${SUCCESS}/${TOTAL} ($(awk "BEGIN {printf \"%.1f\", ($SUCCESS/$TOTAL)*100}")%)%"
```

## 💾 备份与恢复

### 配置备份
```bash
# 导出当前配置
curl http://<IP>/api/config/export > backup_<DATE>.json

# 或使用 GUI 界面：设备配置 → 配置导出
```

### 配置恢复
```bash
# 导入备份配置
curl -X PUT http://<IP>/api/config/import \
  -H "Authorization: Bearer <TOKEN>" \
  -d @backup_<DATE>.json
```

### 工厂重置
```bash
# 恢复出厂设置 (清除所有配置)
curl -X POST http://<IP>/api/system/factory-reset \
  -H "Authorization: Bearer <TOKEN>"
```
