## 编译能力与资源边界

运行时功能开关控制按需资源分配，不消除固件中的已编译代码。经典 ESP32 4MB 目标仅裁剪独立屏幕面板/UI及远程资源三个可选包，保留 PointHistory、通用 I²C、PCF8574、INA226、原有网络和 Web 能力；其他八个目标保留这些可选包。实际编译宏与 Web 能力入口由 `scripts/test-web-profile.js` 同时校验，并覆盖配置错位、遗漏覆盖及误关通用能力的负例。

静态 RAM/Flash 是链接器用量，不等于运行时堆、最大连续块和任务栈峰值。接近应用分区上限的目标需在每次扩展后重新编译检查，不能依赖运行时关闭开关解决 Flash 超限。
