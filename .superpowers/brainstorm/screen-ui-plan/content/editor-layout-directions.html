A · 三栏可视化编辑器（推荐）

页面/组件、画布、属性职责清晰；全局设置使用抽屉或折叠区，固定唯一主保存按钮。

B · 分步向导

新手更容易理解，但频繁调整多个页面时步骤较多，实时拖拽和快速比较较弱。

C · 全自由画布

布局自由度最高，但学习成本和实现复杂度大，触控配置容易失控，不适合当前通用固件的简洁目标。

三种方案共同遵守

预览只预览、不执行真实控制；配置统一保存；心知天气归入设备屏幕；组件与硬件通过能力描述和数据源引用解耦；终端/探测降级到“更多 → 诊断”。
